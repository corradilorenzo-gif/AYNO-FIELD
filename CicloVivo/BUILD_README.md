# CicloVivo Android – build isolata
Questo ramo e la directory CicloVivo sono dedicati alla build dell'app CicloVivo 0.2. 
Il progetto principale AYNO-FIELD su main non viene modificato.
I dati sanitari degli utenti NON sono nel repository: vengono conservati soltanto sul dispositivo.
Il sorgente è conservato temporaneamente nell'archivio xz diviso in cinque parti, e il workflow ne verifica SHA-256 prima della compilazione.
Per il download: GitHub > Actions > CicloVivo - build APK > ultimo run > Artifacts > CicloVivo-0.2-debug-APK.
L'APK di debug è per prova, non una release medica o contraccettiva.
